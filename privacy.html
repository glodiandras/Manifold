Privacy

Privacy information for the static Manifold showcase website.

How the website works

This website uses no cookies, analytics, localStorage, remote fonts or tracking scripts. There is no signup or submission form. The illustrative views work in your browser and have no access to your files.

Hosting

This website can be served by GitHub Pages and other static hosts. The hosting provider may process technical data such as IP addresses and HTTP request information when serving the website, under its own privacy policy.

External links

Following a GitHub link takes you to a service covered by GitHub’s own privacy terms. This showcase and the Manifold desktop application are separate: this website does not connect to your workspace.
